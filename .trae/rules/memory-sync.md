# 项目记忆同步规则（随项目走，进 git，跨电脑同步）

本项目的长期记忆存放在 `.trae/memory/` 目录（注意：Trae 官方的项目记忆
存在系统盘 `~/.trae-cn/memory/`，不随项目走，与本目录是两套并行体系）。

## 读（每次对话开始）

每次对话开始前，先读取 `.trae/memory/` 下的所有 Markdown 文件，
了解项目的历史决策、约束、踩坑记录和当前进度，作为本次对话的上下文。

## 写（每次对话结束）

每次对话结束前，如果本轮产生了对后续有价值的信息，将其总结为简洁要点，
追加或更新到 `.trae/memory/` 下对应的文件：

- `decisions.md`：重要技术决策及原因（做了什么选择、为什么）
- `pitfalls.md`：踩过的坑及解决方案（错误现象 → 根因 → 修法）
- `conventions.md`：项目约定（代码风格、流程、命令）
- `progress.md`：当前进度和待办

## 写入纪律

1. 只追加/更新要点，不堆砌完整对话，保持文件精简可读；
2. 重复或已被后续推翻的旧条目应更新或删除，不无限增长；
3. 文件不存在时按需创建；
4. 不写入密码、密钥、IP 等敏感信息（本目录会提交到 GitHub）；
5. 约定一次只在一台机器上活跃写记忆，换机前 `git pull`，收工 `git push`。
